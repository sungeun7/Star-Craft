# 스타크래프트 스타일 RTS 게임

스타크래프트를 모티브로 한 웹 기반 실시간 전략 게임입니다.

## 기능

### 자원 시스템
- **미네랄**: 건물 건설 및 유닛 생산에 필요
- **가스**: 향후 업그레이드에 사용 (현재 미구현)
- **서플라이**: 인구수 제한 시스템

### 유닛
- **SCV**: 일꾼 유닛, 미네랄 채굴 가능
- **마린**: 기본 전투 유닛

### 건물
- **커맨드 센터**: SCV 생산, 자원 저장
- **배럭**: 마린 생산
- **서플라이 디팟**: 인구수 증가 (+8)

## 조작 방법

### 기본 조작
- **좌클릭**: 유닛/건물 선택
- **드래그**: 다중 선택
- **우클릭**: 이동 명령
- **우클릭 (미네랄)**: SCV에게 채굴 명령

### 건물 건설
1. 사이드바에서 건물 버튼 클릭
2. 맵에서 원하는 위치 클릭
3. 충분한 미네랄이 있으면 건설됨

### 유닛 생산
1. 생산 건물 선택 (커맨드 센터 또는 배럭)
2. 사이드바에서 유닛 버튼 클릭
3. 유닛이 생산됨

## 실행 방법

1. `index.html` 파일을 웹 브라우저에서 열기
2. 게임 시작!
